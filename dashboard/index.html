How the model works

Implied value = TVL × category multiple × growth × maturity × breadth. The multiple is the median market-cap-to-TVL ratio of the live-token protocols in the same category, taken from this snapshot, and only when at least three live protocols back it; a category with fewer uses the global median, so one outlier never prices a whole category. Growth is the seven-day TVL change, clamped. Maturity rises with the days a protocol has run with no token recorded. Breadth adds a little for each extra chain. No protocol name is ever special-cased.
